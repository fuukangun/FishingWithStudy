[![SMAPI](https://img.shields.io/badge/SMAPI-4.0%2B-blue)](https://smapi.io/)

**fishingWithStudy** 是一个将星露谷物语钓鱼小游戏替换为答题系统的模组。你无需再控制那个弹跳的绿色条，只要答对题目就能钓上鱼。边玩游戏边学习！

## 功能特性

### 核心机制

| 功能 | 说明 |
|------|------|
| 答题替代钓鱼 | 鱼上钩后，弹出答题界面而非原版钓鱼小游戏。答对即可钓上鱼。 |
| 单选与多选 | 题目支持单选题和多选题两种格式。 |
| 可配置倒计时 | 默认每题倒计时25秒（可调节5-60秒），可完全关闭。 |

### 难度分级

根据鱼的种类和是否有宝箱，分为四种场景：

| 场景 | 需要答对数 | 说明 |
|------|-----------|------|
| 普通鱼 + 无宝箱 | **1** 题 | 答对即钓上鱼 |
| 普通鱼 + 有宝箱 | **2** 题 | 答对第1题获得宝箱，答对第2题钓上鱼 |
| 传说鱼 + 无宝箱 | **5** 题 | 连续答对5题钓上鱼 |
| 传说鱼 + 有宝箱 | **5** 题 | 答对前3题获得宝箱，答对5题钓上鱼 |

如果中途答错或超时，鱼会逃脱（详见[工作原理](#工作原理)）。

### 智能学习算法

模组会追踪你答错的题目，并在后续答题中定期复习。第一轮全部题目过完后，每答5题会随机插入一道之前答错的题，帮助巩固记忆。

### 品质奖励

全局累计答对 **66 题以上**后，每次钓上鱼时有 **70% 概率**触发品质加成，根据总正确率决定品质：

| 正确率 | 概率 | 品质 |                                                                                                                    
|--------|------|------|                                                                                                                    
| \> 80% | 70% | 铱星 |                                                                                                                     
| \> 70% | 70% | 金 |                                                                                                                       
| \> 60% | 70% | 银 |  

如果 70% 概率未触发，或累计答题不足 66 题，则走原版的鱼品质逻辑。

### 数据统计

- **分类统计**: 按题库和分类组合追踪正确率
- **全局统计**: 追踪终生答题总数和正确率
- 数据通过星露谷的 `modData` 系统按存档持久化保存

### 其他特性

- **GMCM 支持**: 完整集成[通用模组配置菜单](https://www.nexusmods.com/stardewvalley/mods/5098)，游戏内直接修改设置
- **双语界面**: 根据游戏语言自动切换中文/英文
- **时间冻结**: 答题期间游戏时间暂停，不浪费游戏内时间
- **体力返还**: 答对返还抛竿消耗的体力
- **钓鱼经验**: 根据鱼的难度获得钓鱼经验值
- **自定义题库**: 支持从 JSON 文件加载自定义题库

## 工作原理

1. 抛竿等鱼上钩（和原版一样）
2. 鱼上钩后，不弹出原版的钓鱼小游戏（BobberBar），而是弹出**答题界面**
3. 阅读题目，选择答案，点击**确认**
4. 在倒计时结束前答对足够数量的题目即可钓上鱼

**奖励机制与原版的区别：**

| 项目 | 原版 | 本模组 |
|------|------|--------|
| 鱼品质 | 取决于完美钓鱼（保持绿条对准鱼） | 取决于长期答题正确率（累计66题后触发） |
| 宝箱 | 保持绿条覆盖宝箱图标 | 额外答对一题即可获得 |
| 体力 | 无返还 | 答对返还抛竿体力 |
| 经验 | 完美钓鱼有加成 | 按鱼难度分档给固定经验（7/10/13/15） |

**答错时：**

| 场景 | 结果 |
|------|------|
| 普通鱼（不管有无宝箱） | 鱼逃脱，获得一个垃圾，扣除 1-3 点体力 |
| 传说鱼 | 鱼逃脱，无体力惩罚 |
| 已获得宝箱但未钓上鱼 | 保留宝箱，鱼逃脱 |

**超时时（倒计时归零未作答）：**

| 场景 | 结果 |
|------|------|
| 普通鱼（不管有无宝箱） | 鱼逃脱，获得一个垃圾，无体力惩罚 |
| 传说鱼 | 鱼逃脱，无体力惩罚 |

**按 Escape 键**：直接放弃，鱼逃走，无奖励也无惩罚。

## 安装

### 前置要求

- [Stardew Valley 1.6+](https://www.stardewvalley.net/)
- [SMAPI 4.0+](https://smapi.io/)
- [Harmony](https://www.nexusmods.com/stardewvalley/mods/20486)（SMAPI 自带）
- [Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098)（可选，用于游戏内修改设置）

### 步骤

1. 如果还没安装 SMAPI，请先安装
2. 下载 `fishingWithStudy` 最新版本
3. 解压到 `StardewValley/Mods/` 文件夹
4. 通过 SMAPI 启动游戏

```
StardewValley/
└── Mods/
    └── fishingWithStudy/
        ├── fishingWithStudy.dll
        ├── manifest.json
        └── assets/
            └── data/
                ├── questions.en.json
                ├── questions.zh.json
                └── custom/          ← 放自定义题库
```

## 使用方法

### 正常钓鱼

像往常一样钓鱼即可。鱼上钩后答题界面会自动替换钓鱼小游戏。答对题目就能钓上鱼。

### 答题时操作

| 操作 | 按键 |
|------|------|
| 选择/取消选项 | 鼠标左键 |
| 提交答案 | 点击"确认"按钮 |
| 放弃钓鱼 | Escape |

### 学习模式

按下配置的快捷键（默认：**K**）可以随时打开学习模式。学习模式不需要钓鱼，无体力消耗，无奖励——纯粹学习。详见[学习模式介绍](#学习模式介绍)。

## 配置

### 通过 GMCM（推荐）

游戏内菜单 → **模组选项** → **fishingWithStudy** 调整设置。

### 直接编辑配置文件

编辑 `Mods/fishingWithStudy/config.json`：

```json
{
  "TimerEnabled": true,
  "TimerSeconds": 25,
  "SelectedBank": "default",
  "SelectedCategory": "",
  "StudyModeKeybind": "K"
}
```

| 设置 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `TimerEnabled` | bool | `true` | 是否启用每题倒计时 |
| `TimerSeconds` | int | `25` | 每题答题时间，秒（5-60） |
| `SelectedBank` | string | `"default"` | 当前使用的题库 |
| `SelectedCategory` | string | `""` | 题目分类筛选（空=全部） |
| `StudyModeKeybind` | string | `"K"` | 打开学习模式的快捷键 |

## 自定义题库

将自定义的 `.json` 题库文件放入 `assets/data/custom/` 文件夹。每个文件会自动出现在 GMCM 配置菜单的题库选项中。

文件命名：
- 任何以 `.json` 结尾的文件名都可以（如 `math.json`、`history.json`）
- 文件名将作为题库名称显示在菜单中选择

---

## 题库格式

```json
[
  {
    "category": "math",
    "category_i18n": "数学",
    "questionList": [
      {
        "id": "q001",
        "type": "single",
        "question": "2 + 2 等于多少？",
        "options": [
          { "tag": "A", "text": "3" },
          { "tag": "B", "text": "4" },
          { "tag": "C", "text": "5" },
          { "tag": "D", "text": "6" }
        ],
        "answer": ["B"]
      },
      {
        "id": "q002",
        "type": "multiple",
        "question": "以下哪些是质数？",
        "options": [
          { "tag": "A", "text": "2" },
          { "tag": "B", "text": "4" },
          { "tag": "C", "text": "7" },
          { "tag": "D", "text": "9" }
        ],
        "answer": ["A", "C"]
      }
    ]
  }
]
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `category` | string | 是 | 分类标识符，用于筛选 |
| `category_i18n` | string | 否 | 分类显示名称（支持中文） |
| `questionList` | array | 是 | 题目数组 |
| `id` | string | 是 | 题目唯一标识 |
| `type` | string | 是 | `"single"` 单选，`"multiple"` 多选 |
| `question` | string | 是 | 题目文本 |
| `options` | array | 是 | 选项数组（至少2个） |
| `options[].tag` | string | 是 | 选项标识，如 "A"、"B"、"C" |
| `options[].text` | string | 是 | 选项文本 |
| `answer` | string[] | 是 | 正确答案的 tag 数组 |

### 注意事项

- 缺少必填字段的题目会被自动跳过并发出警告
- 重复的题目 ID 会被自动跳过
- 题型必须是 `"single"` 或 `"multiple"`
- 默认题库根据游戏语言自动选择 `questions.zh.json`（中文）或 `questions.en.json`（英文）

## 学习模式介绍

学习模式让你随时可以练习题目，无需钓鱼。做这个模式是为了玩家可以在星露谷游戏中进行刷题，配合自定义题库，玩家们可以在这里备战驾校考试、或者其他培训考试等。

### 使用方式

1. 游戏中按下配置的快捷键（默认：**K**）
2. 学习模式答题界面打开
3. 答题——正确显示绿色，错误显示红色并展示正确答案
4. 答对自动进入下一题
5. 答错或超时显示反馈后自动进入下一题
6. 按 **Escape** 或再次按 **K** 退出

### 与钓鱼模式的区别

| | 钓鱼模式 | 学习模式 |
|--|---------|---------|
| 体力消耗 | 有（答对返还） | 无 |
| 钓到鱼 | 是 | 否 |
| 宝箱 | 是 | 否 |
| 经验值 | 是 | 否 |
| 时间冻结 | 是 | 是 |
| 统计记录 | 是 | 是 |

## 常见问题

### 没有加载题库怎么办？

模组会显示警告并回退到原版钓鱼。确保 `assets/data/questions.{lang}.json` 文件存在且包含有效题目。

### 可以创建多个自定义题库吗？

可以！在 `assets/data/custom/` 中放入多个 `.json` 文件，每个文件都会作为独立题库出现在 GMCM 配置菜单中。

### 如何关闭倒计时？

在 GMCM 或 `config.json` 中将 `TimerEnabled` 设为 `false`。没有时间压力，每道题想答多久答多久。

### 模组对传说鱼有效吗？

有效！传说鱼需要连续答对 5 题。如果带宝箱，第 3 题获得宝箱。答错或超时无体力惩罚，但鱼直接逃走。

### 中途答错已经获得的宝箱会消失吗？

不会。如果你已经答对获得了宝箱，但后续题目答错导致鱼逃脱，宝箱仍然保留。

### 可以自定义学习模式快捷键吗？

可以，在 GMCM 或 `config.json` 中修改 `StudyModeKeybind`。支持 SMAPI 的按键绑定格式（如 `"LeftControl + K"`）。
